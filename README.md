# InferlexAI Website

Static GitHub Pages landing page for `www.inferlexai.com`.

## Video Assets

Place AI-generated MP4 videos at these paths:

- `assets/videos/hero.mp4`
- `assets/videos/industrial-ai.mp4`
- `assets/videos/enterprise-bi.mp4`
- `assets/videos/agentic-workflows.mp4`
- `assets/videos/custom-ai-engineering.mp4`

The HTML already uses semantic looping, muted, inline `<video>` elements for each placement.

## Deployment

GitHub Pages should serve the repository root on the `main` branch. The `CNAME` file must contain only:

```text
www.inferlexai.com
```
